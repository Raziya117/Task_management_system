# 🚀 Task Hive - Task Management Application

## 📌 Overview

Task Hive is a full-stack task management application where users can create boards and manage tasks efficiently.

This project is built using the MERN stack.

---

## 🛠️ Tech Stack

* Frontend: React.js
* Backend: Node.js, Express.js
* Database: MongoDB

---

## ✨ Features

* Create and manage boards
* Add, update, and delete tasks
* REST API integration
* Responsive user interface

---

## 📂 Project Structure

task-hive/
│── backend/
│── frontend/
│── README.md

---

## ⚙️ Installation & Setup

### 1. Clone the repository

git clone https://github.com/your-username/task-hive.git

### 2. Backend setup

cd backend
npm install

Create a `.env` file and add:
PORT=5000
MONGO_URI=your_mongodb_connection_string

Run backend:
npm start

---

### 3. Frontend setup

cd frontend
npm install
npm start
