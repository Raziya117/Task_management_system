# 🚀 Task Hive - Task Management System

## 📌 Overview

Task Hive is a full-stack task management application that helps users organize tasks using boards and track progress efficiently.

Built using the MERN stack (MongoDB, Express.js, React.js, Node.js).

---

## 🛠️ Tech Stack

* Frontend: React.js
* Backend: Node.js, Express.js
* Database: MongoDB
* API: REST APIs

---

## ✨ Features

* Create and manage boards
* Add, update, delete tasks
* Organize tasks visually
* Full CRUD operations
* Responsive UI

## ⚙️ Setup Instructions

### 1️⃣ Clone Repository

```
git clone https://github.com/your-username/task-hive.git
cd task-hive
```

---

### 2️⃣ Backend Setup

```
cd backend
npm install
```

Create `.env` file:

```
PORT=5000
MONGO_URI=your_mongodb_connection_string
```

Run backend:

```
npm start
```

---

### 3️⃣ Frontend Setup

```
cd frontend
npm install
npm start
```
